# Ćao! для iPhone

Это устанавливаемое веб-приложение (PWA), оптимизированное под iPhone.

## Установка
1. Разместите папку на HTTPS-хостинге (GitHub Pages, Netlify или Vercel).
2. Откройте ссылку в Safari на iPhone.
3. Нажмите «Поделиться» → «На экран Домой».
4. Приложение откроется полноэкранно и будет работать офлайн после первого запуска.

Важно: локальный файл index.html можно открыть для просмотра, но установка и офлайн-режим требуют HTTPS.
