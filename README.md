# Ćao! Serbian — исправленная версия 5.0

## Что исправлено
Предыдущая версия создавала тысячи сочетаний широкими шаблонами без проверки части речи,
падежа, рода и семантической совместимости. Поэтому появлялись фразы вроде
«мне нужен спасибо» и «я ищу поздравляю».

В этой версии:
- удалены все случайные сочетания;
- сохранены только исходные словарные единицы и фиксированные разговорные фразы;
- новые предложения создаются только из семантически совместимых наборов;
- формы сербских и русских глаголов заданы отдельно для каждого лица;
- существительные и дополнения хранятся сразу в нужной падежной форме;
- добавлены автоматические проверки запрещённых и пустых сочетаний;
- изменена версия офлайн-кэша, чтобы iPhone загрузил новые данные.

## Содержание
- 3960 проверяемых учебных единиц;
- 60 уроков;
- 15 грамматических тем;
- 89 вручную добавленных употребительных фраз;
- 2520 контролируемых утвердительных предложений;
- 720 контролируемых отрицательных предложений.
