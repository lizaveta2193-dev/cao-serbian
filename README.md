# Ćao! v6 — грамматика для русскоязычных

Добавлено 15 подробных уроков:
произношение, biti, настоящее время, da + глагол, отрицание, вопросы,
четыре падежа, прошедшее и будущее время, прилагательные, клитики и современная речь.

Каждая тема содержит:
- простое объяснение на русском;
- сравнение с русским языком;
- типичные ошибки;
- реальные примеры;
- переход к упражнениям.
